What It Is

A four-wheel remote-controlled rover powered by two ESP32 microcontrollers that talk to each other wirelessly. One microcontroller sits in the rover (the On-Board Computer), the other in a handheld controller (the Control & Telemetry Unit). They communicate using ESP-NOW, a wireless protocol that responds in 1-5 milliseconds—fast enough for real-time control.

The rover reads joystick inputs, drives four motors independently, monitors sensors, and sends live data back to the controller. It handles emergency stops in under 100 microseconds using hardware interrupts.

Why It's Interesting

Low-Latency Wireless Control

ESP-NOW replaces traditional WiFi or Bluetooth. It works without a router, has longer range than Bluetooth, and responds faster than both. Commands travel wirelessly, telemetry comes back in real time.

Hardware Motor Control

Uses the ESP32's built-in Motor Control PWM peripheral instead of basic Arduino functions. This gives precise control over motor timing, speed, and direction for all four wheels independently.

Sensor Fusion

Combines data from an accelerometer, gyroscope, and magnetometer to calculate compass heading even when the rover tilts or rolls. A separate processor core handles sensor reads so motor control never waits.

Dual-Core Processing

One CPU core reads sensors in the background. The other controls motors. They don't interfere with each other. This keeps response time instant.

State Machine Architecture

Both the rover and controller run through formal states: initialized, waiting for connection, armed, running, emergency stop. This prevents unsafe operations and handles errors cleanly.

Designed for Expansion

The architecture can integrate a Raspberry Pi or NVIDIA Jetson for autonomous navigation, computer vision, and path planning. The ESP32 would continue handling real-time motor control and safety while the computer handles high-level decision-making.

Technical Details

Sensors

  • MPU6050 IMU (accelerometer + gyroscope)
  • QMC5883L magnetometer for compass heading
  • GPS receiver for position tracking
  • ACS712 Hall effect sensor (±30A range)
  • DS18B20 temperature sensor
  • 16-bit ADC for voltage/current monitoring

Interface

  • 20×4 LCD display with five-page UI
  • WS2812B addressable LEDs for status
  • Analog joystick with calibration
  • Rotary encoder with hardware debouncing
  • Emergency stop switches

Software Architecture

  • FreeRTOS multi-core task management
  • Background sensor reading at 5Hz
  • Controller update rate: 50Hz
  • Motor response: <1ms
  • Emergency stop: <100µs

Communication

  • ESP-NOW for bidirectional wireless
  • SLIP protocol for USB logging
  • Modular command/telemetry system
  • 1-5ms typical latency

Future Plans

The rover is built to support autonomous operation. The next phase adds a Raspberry Pi or Jetson Nano for computer vision, SLAM (Simultaneous Localization and Mapping), and waypoint navigation. The ESP32 will continue handling real-time control and safety systems while the computer makes high-level decisions.

  • Vision processing for obstacle detection and object tracking using OpenCV
  • SLAM with ROS2 navigation stack using lidar or depth camera
  • GPS waypoint navigation with autonomous path planning
  • Sensor fusion combining ESP32 IMU with vision data
  • Mission planning with hardware-level safety overrides
